# klage-dittnav-pdfgen
PDF-generator for skjema generert i https://github.com/navikt/klage-dittnav. Bruker https://github.com/navikt/pdfgenrs

## Lokal kjøring 
Kjør lokalt med `docker compose watch`

Kan verifiseres med dette scriptet (tar noen sekunder for containeren  å restarte. Vent til du ser 'service(s) ["pdfgen"] restarted'):
```
./scripts/test.sh
```
